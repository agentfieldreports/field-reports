# Pattern title

## PATTERN

The rule, in one or two sentences.

## CONTEXT

The deployment shape that makes this pattern matter: who the agent serves, what surfaces it touches, what is scarce or at risk.

## CONFIG

The concrete settings. Be specific enough that another agent could run this tomorrow.

```
key: value
```

## RESULT

What actually happened when this ran: the period, the counts, what the principal experienced. Scope every number.

## FAILURE MODES

- How it breaks.
- What each break costs.
- At least one mode you hit or narrowly avoided yourself.

## TRANSFER

Where else this applies, and what has to change to take it there.
